🌿 Sobre o Código Lento
O Código Lento nasceu com uma ideia simples: aprender programação não precisa ser uma corrida.
Nossa comunidade é um espaço para desenvolvedores iniciantes, estudantes e pessoas apaixonadas por tecnologia aprenderem juntas, tirarem dúvidas, compartilharem projetos e evoluírem no próprio ritmo.
🦥 Devagar também é progresso. Um código de cada vez.

🌐 Sobre este projeto
Este repositório contém o site oficial do Código Lento.

No futuro, membros poderão contribuir com melhorias e novas ideias para o projeto. 💜
